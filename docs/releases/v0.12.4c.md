## Scalpellino v0.12.4c — Render, step 5c: checked against VRAD's code

Two things were checked in VRAD's own code and now work as Source does.

- **No more seam on bump-mapped surfaces.** VRAD bakes the 3 bump lightmaps as the light
  along each direction; the engine then scales them so they average to the flat
  lightmap. Scalpellino now does the same, so a bump-mapped surface is as bright as the
  same surface without a bump map, and the bumps show at the right strength. Props baked
  per vertex get the same.
- **Texlights at Source's brightness.** VRAD scales surface lights by 100 x 100, as it
  does point lights; Scalpellino didn't. Texlight brightness values now mean what they
  mean in a `lights.rad`: **divide old values by 10000** (a lamp at 60000 is now 6).
- Bakes saved before this version are made again the first time.
