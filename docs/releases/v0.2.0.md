## Scalpellino v0.2.0 — precision

Inspired by Hammer++: keeping geometry clean and on the grid.

- **Vertex tool (Shift+V):** click a corner in a 2D view (corners stacked behind it move
  together), Cmd+click to add more, drag to move them, snapped to the grid. The brush
  updates live; if the shape would stop being a proper solid it turns **magenta** and
  the move isn't applied.
- **Move vertices exactly (Cmd+Shift+T):** move the selected corners by a typed offset,
  or type a corner's exact position.
- **Snap vertices to grid (Cmd+B):** rounds every corner of the selection to the grid —
  e.g. after rotating by an odd angle. Refuses (with a message) if a face would bend.
- **Pivot:** rotate and scale around the selection centre, the world origin, or a typed
  point (Transform → Pivot). Shown as a cyan marker.
- **Grid-friendly angles:** 3:4:5 (36.87°), 5:12:13, 8:15:17, 7:24:25 — rotating by these
  keeps corners on whole numbers when sizes are multiples of 5, 13, 17 or 25. In the
  Transform dialog, and as a drag-rotation snapping option.
- **Any grid size:** View → Set grid size... (e.g. 80), and a microgrid (0.125–0.5) that
  is off by default.

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** `Scalpellino-apple-silicon.zip`

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
