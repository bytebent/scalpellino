## Scalpellino v0.6.0 — workflow and more shapes

**More shapes**
- Block tool (Shift+B) shapes in the Properties panel: **box, wedge, cylinder, cone,
  pyramid, sphere** (with a sides setting). Each is one clean brush. Round shapes stand
  along the view's depth — drawn in the top view they stand upright, like Hammer.
- Curve tool (Shift+C) adds **dome**, **helix ramp**, **straight stairs** (solid or
  floating steps, either direction) and a **centre column** for spiral stairs.

**Seeing what you're doing**
- **Hide selected (H)**, **hide everything else (Shift+H)**, **show all (Cmd+U)**.
- **Visgroups** (tab next to Textures): name groups of brushes and switch them on/off.
  Hidden brushes can't be clicked by accident, and it's all saved with the map.
- **Find overlapping brushes (Cmd+Shift+O):** lists brushes that cut into each other
  (touching is fine) and jumps the camera to each with Next / Prev.
- **Back to the origin:** the "origin" button in each view's corner, or Cmd+0 for all.

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
