## Scalpellino v0.5.0 — curves

**Curve tool (Shift+C).** Pick a shape in the Properties panel (right), drag a box in a
2D view, adjust with the handles or by typing exact values, press **Return**:

- **Arch** — a doorway arch: curved underside, square top and legs (both optional).
- **Ring / pipe / cylinder** — full or partial (start/end angles); thickness = radius
  makes a solid cylinder.
- **Curved wall** — drag from start to end, then drag point 3 to bend it.
- **Spiral stairs** — in the top view: steps, rise, turn, inner radius, direction.
- **Arched opening** — select a wall, draw the opening: it's cut out cleanly.

Every piece is a proper flat-faced brush; neighbours share exact corners (no cracks), and
corners are rounded to whole units by default. Generated shapes stay **editable**: one
click selects the whole shape, Tools → **Edit curve** to change e.g. the number of
segments (it follows if you moved it), Tools → **Bake curve** to turn it into plain
brushes. Saved in the `.map` as a normal `func_group`, so other tools read it fine.

Also new since v0.4.0:
- **Wrap textures around corners:** Texture tool, click a face, Option+Shift+click the
  next one (repeat to go around); or pick several and press **Wrap around**.
- Releases now contain the **Intel** build only (Apple Silicon on demand via Actions).

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** not built automatically; run the `apple-silicon`
  workflow in the Actions tab to get one.

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
