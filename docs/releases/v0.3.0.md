## Scalpellino v0.3.0 — textures

- **Textured 3D view** (View menu switches to flat colours). Two CC0 textures are built
  in: Tile_19 and Bricks_24 (Screaming Brain Studios).
- **Your own textures:** Texture → Add texture folder... (PNG, TGA, JPG, BMP; subfolders
  included). Remembered between sessions.
- **Textures panel** (right): search by name, click a thumbnail to make it current,
  **Apply to selection (Shift+T)**. New blocks use the current texture.
- **Texture tool (Shift+A):** in the 3D view click a face, Cmd+click to add more,
  Shift+click for the whole brush, Option+click to pick up a face's texture.
- **Face panel:** shift, scale, rotation (±90 buttons), Fit (n × m times), Justify
  left/right/top/bottom/centre, Align to world or to the face.
- **Texture menu:** texture lock, default scale for new brushes (0.25), crisp or smooth
  filtering, folders.
- **Endless 2D grid:** build past the classic ±4096 area (the red square stays as a
  reference). The 3D grid is unchanged.

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** `Scalpellino-apple-silicon.zip`

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
