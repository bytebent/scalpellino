## Scalpellino v0.1.0 — brushes

First usable version (milestones 0 and 1).

- Four Hammer-style views (3D, top, front, side) and a tools panel
- Block tool: drag a rectangle, adjust in any 2D view, **Return** creates, **Esc** cancels
- Select tool: click / Cmd+click, move, resize by handles or edges, Shift+drag clone,
  Option+drag a corner to rotate (15° steps), Delete
- Undo / redo, grid snapping, grid size keys (è / +)
- Save and open Valve 220 `.map` files (readable by TrenchBroom and func_godot)
- Fly camera (Z), right-mouse look
- Uses no CPU while idle

Not yet: textures, clip/vertex tools, curves, lighting, exports.

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** `Scalpellino-apple-silicon.zip`

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
