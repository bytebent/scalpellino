## Scalpellino v0.4.0 — shaping

- **Clip tool (Shift+X):** select brushes, drag a line in a 2D view to cut them.
  Three numbered points appear; drag them in any 2D view — moving point 3 in another view
  tilts the cut (3-point clipping, as in Hammer++). Tools → Clip points... lets you type
  them. Keep both pieces, the front or the back (press Shift+X again to switch). The
  preview shows what stays; **Return** clips, **Esc** cancels.
- **Carve with selection (Cmd+Shift+C):** cuts the selected brush's shape out of every
  brush it touches.
- **Hollow (Cmd+Shift+H):** turns a block into a room — walls of the thickness you type.
- **Delete** now works whichever tool is active.

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** `Scalpellino-apple-silicon.zip`

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
