## Scalpellino v0.10.2 — Landing fixes, rectangle select, show / hide

**Snap to land (Cmd+J)**
- Things on top of each other land properly now. An object drops onto the first thing
  below it, and no longer climbs onto a neighbour it overlaps or a shelf above it.
- With several objects selected, one lands on another only if it was stacked on it to
  begin with. Scattered copies (Random Replicate) all go down to the ground instead of
  piling up on each other.
- Props rest on their actual shape, not on the corners of their box, so round or turned
  models no longer float on uneven ground.

**Selecting and showing**
- **Rectangle select in the 3D view:** with the Select tool, drag a rectangle to select
  everything wholly inside it (brushes, primitives, props, lights). Cmd+drag adds to the
  selection; Esc during the drag cancels.
- **View → Show primitives** and **View → Show props** hide or show all of them at once.
  Hidden ones can't be clicked, selected or landed on. Show all (Cmd+U) or adding a new
  one brings them back.

**Smaller fixes**
- A map file with an impossible number (like "nan" or "inf") is refused with a clear
  message instead of opening with broken shapes.
- Undoing back to the last save no longer marks the map as unsaved.
- Two model files with the same name (like `Stone Wall.glb` and `Stone_Wall.glb`) are now
  reported in the Props panel instead of one being hidden without a word.
- The Mac app now reports its real version.
