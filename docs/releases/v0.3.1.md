## Scalpellino v0.3.1 — nodraw, file dialogs

- **nodraw texture:** for faces nobody will ever see (undersides, backs against other
  brushes). It shows as yellow NODRAW in the editor; renders and exports will skip those
  faces. Texture → Apply nodraw, or pick it in the Textures panel.
- **Texture tool:** Cmd+click now takes the whole brush, Shift+click adds or removes
  single faces.
- **Mac file dialogs** for Open (Cmd+O), Save as (Cmd+Shift+S) and adding texture
  folders (Texture folders → Browse...). File → Open by typing a path... is still there.

## Download

- **Intel Mac:** `Scalpellino-intel.zip`
- **Apple Silicon Mac (M1/M2/...):** `Scalpellino-apple-silicon.zip`

## First launch

Unzip to get `Scalpellino.app`. It isn't signed with an Apple developer certificate, so
macOS blocks it the first time:

1. Double-click it once (macOS refuses to open it).
2. Open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Or in Terminal: `xattr -dr com.apple.quarantine /path/to/Scalpellino.app`

Controls are listed in the README.
