## Scalpellino v0.9.4 — Bottega, the shared folder

**Bottega**
- **File → Bottega folder...** picks the one folder shared with Mazzuola and other
  tools. Point it at a new or empty folder (or one with files in it) and it offers to
  make the sub-folders (`textures`, `models`, `maps`, `palettes`, `skies`, `shaders`,
  `renders`, `presets`) and a small `bottega.txt` marker. Your files are never touched.
- Textures in the Bottega's `textures/` folder and skies in `skies/` now show up in the
  Textures panel and the sky list (subfolders included). In a map they go by their path,
  like `textures/walls/Brick_Red`. The built-in textures and your own extra folders keep
  their plain names, so existing maps open as before.
- **Rescan** (File → Rescan Bottega, **Cmd+R**, or the Textures panel's button) picks up
  new files. Nothing rescans by itself, so the app stays at zero CPU when idle.

**Under the hood**
- A test now checks that the app uses no CPU while idle, with a map open (CI runs it).
