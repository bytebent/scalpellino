## Scalpellino v0.10.0 — Props

**Props (models)**
- Put `.glb` models in the Bottega's `models` folder (File → Bottega folder..., then Rescan).
  A folder with one model file is that model (`models/tree`); loose files in `models` work too.
- **Shift+P** (or the Props menu) opens the Props tool; pick a model in the new **Props**
  panel (search by name), click a surface in 3D or a spot in a 2D view, **Return** places
  it, **Esc** cancels. Type exact position, turn and scale in **Properties**.
- Move, turn (rings) and scale props like primitives; **Delete**, **Cmd+D**, **Snap to land**
  (Cmd+J), Snap to ground and **Multi-Replicate** work on them. Each model is loaded once and
  drawn for every copy. Textures and cutout transparency show; fog applies.
- Props are saved in the map with the model's name. If the model is missing the prop shows as
  a box and stays in the map.

**Changed**
- Size handles now scale **evenly** by default, for primitives too. Hold **Shift** to scale
  one axis.
- Props are not physical: no collision, no behaviour.

**Not yet**
- `.mazz` models (waiting for Mazzuola's final format) and the light preview on props.
